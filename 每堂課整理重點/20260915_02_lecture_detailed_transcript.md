## 統計檢定於市場區隔（Market Segmentation）之應用
* **商業決策情境**：
  * 身為銀行行銷經理，擁有數以萬計的客戶資料（包含年齡、工作、婚姻狀態、教育程度、帳戶餘額、有無房貸、有無信貸、與銀行通話時間 duration 等），目標是預測客戶最後是否會購買銀行促銷方案（`decision = Yes / No`）。
  * **核心問題**：如何判定哪些客戶特徵（變數）具備「鑑別力」，適合留下來作為有效率的**市場區隔變數**？
* **區隔變數兩大類型與對應檢定方法**：
  1. **類別型變數（Categorical Variables）**：如婚姻狀態（單身/已婚/離婚）、有無房貸（Yes/No）、有無信貸（Yes/No）。$\rightarrow$ **採用卡方獨立性檢定（Chi-Square Test）**。
  2. **數值型變數（Numeric Variables）**：如帳戶餘額（Balance）、通話時間（Duration）、年齡（Age）。$\rightarrow$ **採用雙樣本 T 檢定（Two-Sample t-Test）**。

## 卡方獨立性檢定（Chi-Square Test of Independence）
* **原理與假設設定**：
  * 虛無假設 $H_0$：兩類別變數相互獨立（無關聯，例如：性別與車型選擇無關）。
  * 對立假設 $H_1$：兩類別變數相互依賴（有機密關聯，適合留作市場區隔）。
* **卡方統計量與 $p$-value 邏輯**：
  $$\chi^2 = \sum \frac{(O - E)^2}{E}$$
  * $O$（Observed）：實際觀察頻率；$E$（Expected）：期望頻率（公式：$E = \frac{\text{列總和} \times \text{行總和}}{\text{總樣本數}}$）。
  * **卡方值越大 $\rightarrow$ 實際與期望偏離越大 $\rightarrow$ 右尾機率 $p$-value $< 0.05 \rightarrow$ 拒絕 $H_0$**：代表兩變數顯著相關，行銷經理可成功保留該變數進行精準行銷！
* **Excel 中的卡方檢定實作（以銀行客戶為例）**：
  1. 使用 `=COUNTIFS()` 建立交叉表（Contingency Table），計算各組合的實際次數 $O$。
  2. 依據列總和與行總和計算各儲存格的期望次數 $E$。
  3. 使用 Excel 公式 `=CHISQ.TEST(實際數值範圍, 期望數值範圍)` 算出 $p$-value。
  4. **實證結果**：
     * **婚姻狀態（Marital Status）**：$p < 0.05$（顯著相關，有效區隔變數）。
     * **房貸（Housing Loan）**：$p < 0.05$（顯著相關，有效區隔變數）。
     * **個人信貸（Personal Loan）**：$p < 0.05$（顯著相關，有效區隔變數）。
* **跨領域延伸應用（製造業品質管理）**：
  * 將行銷變數替換為製造業變數：例如「膠料種類（銀膠/鋁膠/銀鋁膠）」與「產品品質（良品/瑕疵品）」。透過卡方檢定即可判定封裝膠料是否為導致產品瑕疵的關鍵因子。

## 數值型變數之 T 檢定與 Excel 進階篩選（Advanced Filter）
* **資料切割問題**：
  * 若要檢定「買促銷方案的客戶（`Yes`）」與「不買的客戶（`No`）」在**帳戶餘額（Balance）**上是否有顯著差異，必須先將整份資料表拆分為 `Yes` 群組的 Balance 欄位與 `No` 群組的 Balance 欄位。
* **Excel 進階篩選（Advanced Filter）操作步驟**：
  1. 在空白區域設定條件標籤（例如：`Loan = Yes` 或 `Decision = Yes`）。
  2. 點選 `資料` $\rightarrow$ `進階`。
  3. 資料範圍選取全表（$A1:AF4521$），指定複製位置（如 $AH1$ 欄與 $AI1$ 欄），快速將符合條件的 Balance 數據自動抽離出來。
* **執行 F 檢定與 T 檢定**：
  1. 針對抽離出的 `Yes` 群與 `No` 群 Balance 數據執行 F 檢定，判定變異數是否同質。
  2. 依據 F 檢定結果選用對應的 T 檢定。
  3. **實證結論**：$p < 0.05$，證明兩群客戶的帳戶餘額有顯著差異，帳戶餘額為成功的行銷區隔 KPI！
