## 1. 統計檢定與市場區隔之跨領域結合
### 1.1 傳統行銷檢定工具複習
* **三大核心統計檢定**：
  1. **卡方檢定 (Chi-Square Test)**：用於兩個「類別變數 (Categorical Variables)」之間的獨立性檢定（如：性別與產品偏好）。
  2. **T 檢定 (T-Test)**：用於比較兩組樣本在「連續型數值變數 (Continuous Variables)」上的平均值差異。
  3. **F 檢定 (F-Test)**：用於檢定兩組樣本的「變異數 (Variance)」是否相等，作為選擇何種 T 檢定公式的前提條件。
* **跨領域應用**：無論是商業上的顧客市場區隔、公司財務預警（破產預測），或是醫療診斷，其核心邏輯皆為**將樣本分類，並尋找能有效區隔兩者的特徵變數**。

### 1.2 醫療資料集範例：Pima 印第安糖尿病資料集
* **資料集背景**：收集北美洲 Pima 印第安部落原住民的臨床生理數據。該部落具有遺傳性罕見糖尿病的高發病率。美國電視廣告滿滿都是疾病與藥物廣告，醫療機構希望瞭解哪些生理因子與是否發病（Outcome: 1 = Diabetes, 0 = Healthy）有顯著關聯。
* **目標**：從收集到的 8 個生理變數中，找出能夠精準區隔生病與未生病對象的 **KPI（Key Performance Indicators）**。

## 2. 利用 T 檢定辨識關鍵績效指標 (KPI) 的數理邏輯
### 2.1 為何不能用卡方檢定？
* **變數型態分析**：
  * **依變數 (Y / Outcome)**：生病 vs. 未生病（二元類別變數）。
  * **自變數 (X)**：血糖濃度（Glucose）、血壓（Blood Pressure）、BMI、皮脂厚度（Skin Thickness）等（連續型數值變數）。
* **選用工具**：因為自變數為「連續數值」，故無法使用卡方檢定，必須採用 **T 檢定**。

### 2.2 T 檢定辨識 KPI 的核心邏輯
1. **分組 (Grouping)**：將所有受測對象依據最終結果分成兩群——「有生病群 (Y=1)」與「無生病群 (Y=0)」。
2. **比較平均值**：計算並比較這兩群人在某項數值指標（如血糖濃度）上的平均數 (μ1 vs. μ2)。
3. **判定鑑別力 (KPI 判定)**：
   * **若 μ1 ≠ μ2 (p < 0.05)**：代表該指標在兩群人之間存在顯著差異，具備強大的鑑別力，可被認定為 **KPI**。
   * **若 μ1 = μ2 (p ≥ 0.05)**：代表該指標無法有效區分生病與否，不具備鑑別力。

### 2.3 商業平行應用：公司破產預測 (Bankruptcy Prediction)
* **分類對象**：將公司分為「財務危機/破產公司」與「財務健全/健康公司」。
* **指標檢定**：以「存貨周轉率 (Inventory Turnover)」為例，若破產公司的平均存貨周轉率顯著低於健康公司 (p < 0.05)，則存貨周轉率即可作為企業財務預警的 KPI。

## 3. 資料前處理與資料清洗 (Data Cleaning) 實務
在進行任何統計分析或機器學習建模之前，必須先對原始資料進行**敘述性統計 (Descriptive Statistics)** 檢視，辨識並處理異常值。

### 3.1 原始數據異常值診斷 (以 Pima 768 筆資料為例)
* **懷孕次數 (Pregnancies)**：出現 0 次為合理現象（未懷孕）。資料中出現懷孕高達 10 次、11 次者亦屬真實現象。
  * *老師課堂感嘆與東亞/美國生育率對比*：亞洲（特別是台灣與南韓）生育率極低。南韓近年棒球賽贏台灣時，KBS 與 C-Electronics 收視率極高，生育率近期微幅拉升，但台灣少子化依然嚴峻。美國白人家庭多數生育 2 個以上小孩，雖然通膨嚴重且 5~6 成美國人未曾出過國，但生育意願仍高。
* **血糖濃度 (Glucose) = 0**：不合理！人在活體狀態下血糖不可能為零，此為數據登錄缺失（Missing Value）。
* **血壓 (Blood Pressure) = 0**：不合理！生理上沒有血壓代表生命跡象停止（老師幽默開玩笑說：「這不是《行屍走肉》Walking Dead 喪屍，喪屍才沒有血壓」）。
* **皮膚厚度 (Skin Thickness) = 0**：不合理！出現 374 次 0。
* **胰島素 (Insulin) = 0**：不合理！出現 227 次 0。
* **BMI = 0**：不合理！身高體重不可能為零。

### 3.2 資料清洗 (Data Cleaning) 策略與 Excel 高級篩選操作
* **處理方式**：資料缺失可選擇插補（Imputation）或直接移除（Deletion）。本範例採用直接**刪除不合理列 (Remove Invalid Records)**，以確保數據純淨。
* **清洗規模**：原始資料共有 **768 筆**，刪除所有包含 0 異常值的列後，留下 **392 筆** 乾淨資料（Clean Data）。

#### 🛠️ Excel 高級篩選 (Advanced Filter) 步驟：
1. **設定不等於符號**：在 Excel 的準則區域（Criteria Range）中使用 `<>` 符號代表「不等於」（例如：`Glucose <> 0`、`BloodPressure <> 0`、`BMI <> 0`）。（註：在 R 或 Python 中不等於寫作 `!=`）。
2. **選擇輸出位置**：將篩選出來的不含 0 資料，複製並輸出至新的欄位區域（欄位 R 到 Z）。
3. *課堂說明*：老師說明昨天晚上進行線上會議與輔導，今天特別親自開車前來實體上課，主因是必須帶領大家親自安裝與設定 **R** 與 **RStudio** 軟體，這是後續執行聯合分析與品牌定位等複雜模組的基礎。

## 4. 第二階段資料整理：針對 T 檢定進行分組拆拆
在 Excel 中執行雙樣本 T 檢定時，混在一起的資料無法直接選取，必須進行第二次高級篩選，將資料按Outcome獨立拆開：

* **第一群 (無糖尿病群 / Outcome = No / 0)**：選取 `Outcome = No`，篩選後得到 **263 筆** 資料，存放於欄位 AE 與 AF。
* **第二群 (有糖尿病群 / Outcome = Yes / 1)**：選取 `Outcome = Yes`，篩選後得到 **131 筆** 資料，存放於欄位 AC 與 AD。
* **數據驗證**：131 + 263 = 394 列，扣除最頂端的表頭列後，實質樣本數精準為 **392 筆**。

## 5. 兩階段統計檢定實作：F 檢定 → T 檢定
以皮膚厚度（Skin Thickness）為例，檢定有糖尿病與無糖尿病兩群人是否存在顯著差異。

### 第一步：雙樣本 F 檢定 (F-Test for Equality of Variances)
* **目的**：確認有糖尿病群（AD1:AD131）與無糖尿病群（AF1:AF263）在皮脂厚度上的「變異數（方差）」是否相等，以決定後續 T 檢定應選擇「假設變異數相等」還是「假設變異數不相等」。
* **檢定結果**：
  * **F 檢定 p-value = 0.16**（即 16%）。
  * **統計判決**：因 p = 0.16 > 0.05，未達顯著水準，**接受虛無假設 H0**。
  * **結論**：有生病與無生病兩群人在皮脂厚度上的**變異數相等 (Equal Variance)**。
* *連結作業一*：變異數相等代表這兩個族群（或投資區域）的數據波動度（Volatility）是一致的。

### 第二步：雙樣本 T 檢定 (Two-Sample T-Test Assuming Equal Variances)
* **選擇模型**：根據 F 檢定結果，選取 Excel 中的「**假設變異數相等的雙樣本 t 檢定**」。
* **檢定結果**：
  * **單尾與雙尾 p-value 均 < 0.05**（遠小於 5% 顯著水準）。
  * **統計判決**：拒絕虛無假設 H0。
  * **最終結論**：有糖尿病群與無糖尿病群的**平均皮膚厚度顯著不相等 (Equal Variance but Unequal Means)**！
* **管理與決策意涵**：皮膚厚度成功被驗證為具備高度統計鑑別力的 **KPI**，醫療人員可以將皮膚厚度作為預測糖尿病發病風險的重要指標。

## 💡 總結與下階段預告
1. **資料處理標準 SOP**：原始資料 → 敘述統計查錯 → 高級篩選刪除異常值 (Data Cleaning) → 依類別拆群 → F 檢定確認變異數 → T 檢定確認平均值差異 → 產出 KPI。
