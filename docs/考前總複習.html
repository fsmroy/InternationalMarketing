① 統計檢定：卡方 / T / F 三兄弟

「你要知道 F 檢定、T 檢定跟卡方檢定，他們三個呢，然後在行銷上怎麼應用的，這個你要知道。卡方檢定處理是類別變數，T 檢定處理的是數字變數……」

1.1三大檢定對照表（本區最重要的一張表）

檢定資料型態檢定對象（H₀）行銷應用場景關鍵輸出
卡方檢定
Chi-Square		 類別 × 類別（婚姻狀況、有無房貸、性別、車型） 兩類別變數獨立（無關） 市場區隔：檢定婚姻狀況／有無房貸是否影響產品購買 χ² 值越大 → p<0.05 → 該變數是有效區隔變數
T 檢定 數字（連續）× 類別（兩群比較） 兩群平均值相等（μ₁=μ₂） 篩選具鑑別力的 KPI：糖尿病患 vs 健康者的血糖／皮膚厚度；會／不會參加銀行促銷者的帳戶餘額 p<0.05 → 該變數有鑑別力 → 可當預測 KPI
F 檢定 數字 × 數字（兩群波動） 兩群變異數相等（σ₁²=σ₂²） 比較台股 vs 外國股市的年化波動度／風險；T 檢定前必須先做 p≥0.05 變異數相等 → 選「假設變異數相等之 T 檢定」，反之亦然

1.2實作順序與觀念（邏輯題最愛考）

  1. 先 F 後 T：F 檢定確認變異數同質性 → 依結果選擇正確版本的 T 檔定（var.equal）。
  2. 卡方期望值：$E=\dfrac{\text{列總和}\times\text{行總和}}{\text{總樣本數}}$，統計量 $\chi^2=\sum\frac{(O-E)^2}{E}$。
  3. 變數是數值型（年齡、帳戶餘額）但想看「會不會買」→ 先依結果分兩群 → 改用 T 檢定（不是卡方）。
  4. Pima 案例：血壓、血糖、皮膚厚度等出現 0 值是不合理缺失值（Walking Dead Data），先清洗（768 → 392 筆）再 T 檢定，顯著者（血糖、皮膚厚度）當 KPI。
⚠️ 複選題命題邏輯
  • 「下列哪些組合的檢定方法正確？」→ 抓資料型態配對：類別×類別＝卡方；連續×二分群＝T；先 F 後 T。
  • 「p<0.05 代表什麼？」→ 在 95% 信心水準下拒絕 H₀（兩變數相關／兩群平均顯著不同），不是「證明因果」。
  • KPI 語意：T 檢定顯著＝該變數「能區分兩群」＝有鑑別力 → 可作 KPI。
💡 記憶錨點

「類別配卡方、數字配 T、做 T 之前先 F」——老師上課反覆唸的口訣就是答案本身。

② 時間序列與預測模型：SMA / EMA / 線性迴歸

授課：09/08（SMA、EMA、MLR 導論）、09/15（Train/Test Split、Adjusted R²）｜投影片：迴歸預測 p6–19

🎙️ 老師口語（10/20 點名必考）

「移動平均法、指數平滑法，還有所謂的線性迴歸……到底是平滑常數越大誤差會越小還是越大，這個也要注意一下。那所謂的線性迴歸，要知道就是 R² 跟調整後的 R² 有什麼差別。」

— 10/20 課堂逐字稿

2.1SMA 簡單移動平均

  • 以過去固定 $n$ 期算術平均當下期預測：$F_t=\frac{A_{t-1}+\dots+A_{t-n}}{n}$，各期等權重。
  • n 大（20 日月線、60 日季線）→ 平滑效果強、反應遲鈍；n 小（5 日週線）→ 對最新價格反應敏感。
  • 實務：台股加權指數、台積電個股的 5／10／20 日線。

2.2EMA 指數平滑（α 是必考點）

Ft = Ft−1 + α(At−1 − Ft−1) = αAt−1 + (1−α)Ft−1，α ∈ [0, 1]
平滑常數 α行為適用情境誤差表現
α 大（0.4–0.5）最新實際值權重高 → 對最新波動反應迅速動態劇烈變動的環境在劇烈變動環境中誤差較小
α 小（0.15–0.2）保留歷史經驗多 → 穩定、過濾雜訊穩定環境、要濾掉異常波動在穩定環境中表現好
α = 1退化成天真預測（Ft=At−1）僅作基準比較風險過高，實務不宜

2.3三大誤差指標與「為何 MAPE 優先」

  • MSE：平方 → 對大誤差懲罰更重；MAE/MAD：平均偏離的單位大小。
  • MAPE 以百分比呈現相對誤差，能消除公司規模與數據單位（Scale Effect），方便不同量體產品／公司間比對 → 老師欽點的優先指標。

2.4多元線性迴歸 MLR 與 R² 之辨

  • 概念：不是純看時間，而是引入外部因子 X（如台積電五大客戶——蘋果、輝達、超微、高通、聯發科——的營收）預測 Y（營收、EPS）。
  • R²：隨自變數增加只升不降 → 容易「虛胖」。
  • Adjusted R²：加入自變數數量 k 與樣本數 T 的懲罰項；塞入無效變數（Garbage X）會下降 → 評估多元迴歸以調整後 R² 為準。
  • 係數 p<0.05 → 該自變數在 95% 信心下具獨立預測力。

2.5訓練集／測試集切分（09/15 重點）

  • 目的：防止過度配適 Overfitting——全量資料擬合度高 ≠ 對未來有預測力。
  • 訓練集 2011–2022：切在 2022 年底，因 2022 走完完整空頭（升息、通膨、晶片供過於求），模型學過完整多空循環。
  • 測試集 2023–2025：不參與建模，專驗證跨期泛化能力；用 SUMPRODUCT 套迴歸式算預測值，再比 RMSE／MAE／MAPE。
⚠️ 複選題命題邏輯
  • 「α 越大，對最新波動越敏感」對；「α 越大誤差一定越小」錯——要看環境是否劇烈變動。
  • 「加一個變數 R² 一定不變或上升、Adjusted R² 可能下降」→ 標準考句。
  • 「為何用 MAPE 不用 MSE？」→ 答消除 Scale 影響，可跨規模比較。
💡 記憶錨點

n/α 大＝靈敏、小＝遲鈍；「虛胖」的是 R²，減肥懲罰的是 Adjusted R²。

③ 多準則決策：AHP 與 TOPSIS

授課：10/06、10/09（含複習）｜投影片：通路管理 p31–65（AHP 藍牙喇叭案例、TOPSIS Hwang & Yoon 1981）

🎙️ 老師口語（10/20 點名必考）

「AHP 的量它是會介於 1 到 9……那 TOPSIS 幹嘛，就是幫你做排序……當你在計算距離的時候，如果你把所算出來的權重含進來，會發現沒有整合 AHP 得到的排名跟整合 AHP 的排名是差蠻多的……」

— 10/20 課堂逐字稿

3.1AHP 層級分析法

  • 應用情境：NPD 方案評選、供應商評選（品質、交期、成本、永續四準則）、通路位置評選、可攜式藍牙喇叭選購。
  • 尺度：1–9 相對偏好（優為 1~9、不優為其倒數 1/1~1/9），矩陣對角線 aii=1，具倒數（Reciprocal）特性 aji=1/aij；不是李克特量表。
  • Saaty 認知極限：人腦 $7\pm2$ → 評估準則建議 5～7 個以內，避免遞移律矛盾（A>B、B>C 卻填 A<C）。

近似法求權重三步驟（老師口述原順序）：

行總和 → 標準化 → 列平均（各準則權重加總必為 100%）

一致性檢定：

λmax = (1/n)Σ(AW)i/Wi　→　CI = (λmax−n)/(n−1)　→　CR = CI / RI
  • 門檻：CR < 0.1 才算通過（問卷品質合格）。

3.2TOPSIS 逼近理想解排序法

  • 流程：決策矩陣 → 向量正規化 → 乘 AHP 權重 → 找正理想解（效益型取最大／成本型取最小，老師比喻「高富帥／白富美」）與負理想解 → 算各方案歐氏距離。
  • 貼近度：$C_i=\dfrac{D_i^-}{D_i^+ + D_i^-}\in[0,1]$，越接近 1 越優。
  • 排名翻轉 Rank Reversal（必考）：無權重版 vs 結合 AHP 權重版（如交期權重占 47.7%）排名差很多——交期滿分的供應商逆轉奪冠。老師：「整合 AHP 得到的排名跟沒整合的是差蠻多的。」
⚠️ 複選題命題邏輯
  • AHP 尺度描述題：選「1–9＋倒數、成對比較」，排除「0–10 評分」「李克特 5 點量表」。
  • 步驟順序題：行總和→標準化→列平均（不可顛倒）。
  • CR 門檻：<0.1 通過；CI、RI 的角色（CR=CI/RI）。
  • TOPSIS 題：C_i 是「離負理想解遠、離正理想解近」的度量；結合 AHP 權重可能改變排名。
💡 記憶錨點

AHP＝算權重（1–9 成對比較）；TOPSIS＝算排序（理想解距離）；兩者合體會翻盤。

4.1四大屬性 × 老師的感情比喻（看圖判斷的鑰匙）

屬性曲線行為老師的比喻記憶點
一維 O做了開心、不做不開心（線性）熱戀男女：付出多一分、甜蜜多一分成正比
魅力 A有→極致驚喜；沒有→可接受（不失望）小三：出現很驚喜，不出現日子照過有會哇、沒有還好
必要 M有→理所當然；沒有→極度沮喪老夫老妻／家人：像少了半顆心基本盤，缺了爆炸
反向 R有→不滿；沒有→反而輕鬆怨偶：在一起痛苦，分開解脫多多益「善」的反面
無差異 I有沒有都沒感覺（對照組，補充）不加分不減分

4.2量化公式（複選題計算邏輯）

喜悅度 D⁺ = A + O − R　｜　厭惡度 D⁻ = O + M − R　｜　綜合效用 = P·D⁺ + (1−P)·D⁻
  • 問卷判定：以「功能存在／不存在」兩題交叉分類（我喜愛／我期待／沒感覺／勉強／厭惡五級反應），矛盾回答記 Q（Questionable，無效）。
  • 看懂公式邏輯：O 同時貢獻喜悅與厭惡；A 只加喜悅；M 只加厭惡；R 兩邊都扣。

4.3Excel Solver 產品規格最佳化

  • 決策變數：各產品特徵 Xj ∈ {0,1}（二元規劃）。
  • 限制式：預算／成本上限（如總成本 ≤ 5,000 元），且搭配低階／中階／高階價格帶區間。
  • 目標式：Max 喜悅度 D⁺ 或 Min 厭惡度 D⁻ → 自動解出最佳特徵組合。
⚠️ 複選題命題邏輯
  • 給一張 Kano 曲線圖問「哪個點是魅力屬性」→ 用比喻反推：驚喜型＝A、線性型＝O、底線型＝M、負向型＝R。
  • 計算題：給 A/O/M/R 分數 → 代 D⁺、D⁻ 公式比大小。
  • Solver 三要素題：決策變數（0/1）、限制式（預算）、目標（Max D⁺／Min D⁻）。
💡 記憶錨點

熱戀＝O、小三＝A、老夫老妻＝M、怨偶＝R——老師上課的比喻就是答題鑰匙。D⁺ 看歡喜（A+O−R）、D⁻ 看抓狂（O+M−R）。

5.1異常值檢測 Outlier Detection

情境工具特點
單一特徵（一個指標）盒鬚圖 Boxplot以四分位距劃出上下界，界外即異常個案
多特徵（引入共變數）馬氏距離 Mahalanobis Distance同時考量多特徵間的相關性與變異數（結合卡方檢定概念），距離異常大者標為 Outlier

兩大實務應用（老師欽點案例）：

  • 信用卡盜刷：選特徵——刷卡金額、刷卡頻率、貨幣別 Currency——計算馬氏距離，異常即標註盜刷。
  • 資安駭客入侵：監控系統網路流量 Traffic Load，出現爆發性異常＝遭流量攻擊或癱瘓。

5.2K-Means 分群演算法

  • 性質：非監督式學習，市場切分沒有標準答案，由管理者依商業需求決定。
  • 目標：群內距離最小化、群間距離最大化。

迭代五步驟：

  1. 隨機指定 $K$ 個初始中心點（Initial Centroids）。
  2. 計算每個資料點到各中心的距離，分配給最近者。
  3. 重新計算各群的平均中心點（Mean Centroids）。
  4. 資料點依新中心重新歸派。
  5. 重複迭代直到中心點移動極微小 → 收斂／停止條件 Stop Criterion。

Iris 花卉 K=3 vs K=2（課堂實例）：

  • Setosa 山鳶尾：特徵極鮮明，獨立穩成一群。
  • Versicolor 與 Virginica：特徵高度重疊；K=2 時兩者幾乎完全合併，證明其極相似。

24 種評估指標與簡化原則（複選題拉鋸情境）：

  • 分群套件提供 24 種指標（DB Index、Hubert-Arabie 等），分「群間差異（越大越好）」與「群內差異（越小越好）」兩派。
  • 11 個指標建議 K=2、11 個建議 K=3 拉鋸時 → 依「簡化原則 Parsimony」選結構更精簡的 K=2。
⚠️ 複選題命題邏輯
  • 步驟順序題：初始中心 → 指派 → 新中心 → 重新指派 → 收斂停止。
  • 觀念題：K-Means 是非監督式、無標準答案；目標是群內小、群間大。
  • 情境題：指標拉鋸 → Parsimony 選小的 K；單特徵 → Boxplot、多特徵 → 馬氏距離；盜刷看金額／頻率／貨幣別、資安看流量。
💡 記憶錨點

「11 比 11 拉鋸 → 聽 Parsimony 的，選 K=2」；「盜刷三寶：金額、頻率、貨幣別」。

⑥ 關聯規則：Support / Confidence / Lift

授課：09/22（三大指標、Titanic 實作）、09/29（Apriori 剪枝）｜投影片：關聯規則.pdf 全份、促銷策略 p17–30

🎙️ 老師口語（10/20 點名必考）

「關聯規則……你至少知道那個有三個特徵，記得喔：Support、Confidence、Lift，他們是代表什麼……我基本上考複選題嘛，就是不是讓你背嘛，可是你不了解（就答不出），所以這個你要回去去複習。」

— 10/20 課堂逐字稿

6.1三大指標與行銷意義

指標公式白話行銷意義
Support 支援度$P(A\cap B)$＝同時包含 A、B 的交易數 / 總交易數A、B 同時出現的普遍性規則夠不夠「量」，值太小沒有商業價值
Confidence 信賴度$P(B|A)$＝Support / P(A)買 A 的人當中，也買 B 的條件機率搭售／貨架陳列的直接依據
Lift 增益比Confidence / P(B)相對「本來就會買 B」的增益倍數>1 正相關適合搭售；=1 獨立；<1 負相關互斥

6.2兩個老師欽點案例

  • 啤酒與尿布：經典共現案例 → 聯合促銷、貨架陳列（Shelf Management）。關聯規則是共現、不是因果。
  • 茶與咖啡反常案例（複選題陷阱）：Confidence 高達 75%，但 Lift < 1 → 搭茶反而抑制咖啡消費（負相關）。信心度高 ≠ 有用，一定要看 Lift。

6.3組合爆炸與 Apriori 剪枝

  • d 個商品可產生 $3^d-2^{d+1}+1$ 條規則；100 個商品 → 約 $5.15\times10^{47}$ 條規則，暴力法不可行。
  • Apriori 先驗原理：若項集不頻繁（Support 未達門檻），其所有超集必不頻繁 → 由下而上逐層搜尋、剪枝 Pruning。
  • 兩步驟：① 產生頻繁項目集（≥minsup）② 由頻繁項目集產生高信心規則（≥minconf）。

6.4Titanic 實作洞察（09/22）

  • 連續變數離散化（年齡切 Young/Adult/Elder、票價切 Cheap/Medium/Expensive）、na.omit() 去缺失，RHS 設 Survived=Yes/No。
  • 高獲救規則：Class=1st ＋ Sex=Female（頭等艙女性）；高死亡規則：Class=3rd ＋ Sex=Male（三等艙男性）。
  • 延伸警惕：盲目等寬切分會因離群值導致規則自相矛盾（同一區間同時出現在正反 KPI），應配合領域知識切區間。
⚠️ 複選題命題邏輯
  • 三指標定義配對題（機率式 vs 條件式 vs 比值）。
  • 「Confidence 75%、Lift<1 該怎麼解讀？」→ 負相關、不應搭售——這是老師上課特別演的數字。
  • Apriori 剪枝原理（不頻繁子集的超集必不頻繁）與組合爆炸量級。
💡 記憶錨點

Support 看量、Confidence 看條件、Lift 看真相；「Lift<1，搭了反而賣更差」。

⑦ 品牌定位（MDS / CA）與聯合分析

授課：09/29（MDS）、10/09（Conjoint、CA/MCA）｜投影片：品牌定位.pdf p36–51、產品策略 p33–42（Kansei）

🎙️ 老師口語（10/20 點名必考）

「聯合分析……這裡最頭痛就是你要去排序……哪一個特徵在消費者心目中它是最 care 的，這個叫重要性……效用值跟重要性是不一樣的……這些細節跟這些邏輯的過程基本上都在我們命題範圍。」

— 10/20 課堂逐字稿

7.1MDS 多維尺度分析

  • 定位：PCA 的無母數版本（免常態分配假設），把高維屬性／評分矩陣降到 2D/3D 知覺圖 Perceptual Map。
  • 品質指標：壓力係數 Stress Value < 0.05 才算有效投射（越小越好）。
  • 案例：10 個汽車屬性（馬力、內裝、價格、科技感…）降維成 2 維，看 Toyota/Honda（日系）vs 雙 B（德系）、Tesla 的競爭空間與親疏。

7.2CA 對應分析

  • 基於交叉表（列聯表）的類別資料分析 → 產出雙標圖 Biplot：品牌與市場區隔（High/Medium/Low）同時投影在同一張圖。
  • 案例：咖啡品牌（星巴克、路易莎、85度C、單堤、HWC）× 消費階層（Low/Medium/High）的對應空間，直觀看出品牌–客群親和度。

7.3聯合分析 Conjoint Analysis

  • 目的：量化消費者對各屬性（Attributes）×水準（Levels）的偏好效用（Part-worth Utility），用 dummy variable 迴歸估出。
  • 正交陣列 Orthogonal Array：全因子組合過多（如 $2\times3^5=96$ 組）→ 部分因子設計縮成 16 組正交代表性卡片。
  • 排序三階段技巧（16 組 Profile）：最喜歡 5–6 個 → 最討厭 5–6 個 → 中間 4–5 個，降低受訪者認知負擔。
  • 偏好分數轉換：Preference Score = 17 − Rank。

效用 vs 重要性（老師點名「最頭痛」的觀念）：

概念定義關鍵性質
效用 Utility各屬性各水準的偏好分數同一屬性內各水準效用相加必為 0
重要性 Importance各屬性效用全幅 Range（max−min）占全部屬性全幅總和的百分比Range 越大 → 該屬性在消費者心中越重要（與重要性成正比）
⚠️ 複選題命題邏輯
  • 「效用值高」與「屬性重要」是兩件事——重要看 Range，不是單一水準效用。
  • 數字記憶題：Stress<0.05、96→16 卡片、排序三階段 5-6/5-6/4-5、Preference=17−Rank、同屬性效用和=0。
  • MDS vs CA 差異：MDS 用相似度/評分降維（無母數、看 Stress）；CA 用交叉表類別資料、產 Biplot。
💡 記憶錨點

「Range 大＝心之所向（重要）；效用和＝0」；MDS 看 Stress、CA 看 Biplot。
