初學者最常犯的錯

  • 只看 Console 最下面一行。錯誤訊息通常有紅色字，要整段看。
  • 改了程式碼卻沒重新執行。改了要再按一次 Ctrl+Enter 才會生效。

題目一市場區隔 — 統計檢定

📄 作業原文（English Original）

Based on bank dataset, remove the following columns: job, contact, pdays, poutcome, month, and day. Then, conduct market segmentation using statistical tests with regard to the response "y" (participating in promotion plan or not). For categorical features, apply Chi-square tests. For numerical features, please apply F test first to justify equal variance or not (between two groups, participating vs. non-participating) and then apply T tests to justify equal mean or not. Suppose you are marketing manager, indicate that what features are suitable to conduct market segmentation? Then, address managerial insights for the above-mentioned results.

📋 題目說明

以 bank 資料集為基礎，先移除以下 6 個欄位：jobcontactpdayspoutcomemonthday。

接著針對反應變數「y」（是否參與促銷方案）做市場區隔的統計檢定：

  • 類別型特徵 → 用卡方檢定（Chi-square test），檢定該特徵與 y 是否獨立。
  • 數值型特徵 → 先做 F 檢定判斷「參與 vs 未參與」兩組的變異數是否相等，再依結果選對應的 T 檢定判斷兩組平均數是否相等。

最後以行銷經理的角度回答：哪些特徵適合作為市場區隔的依據？並提出管理意涵。

🖱️ 操作步驟

1開啟 R/hw2_q1.R。
2選取 第 0 段 ~ 第 1 段（setwd + read.csv + str + head）→ Ctrl+Enter。
3依序往下，每段執行一次：第 2 段移除欄位 → 第 3 段欄位分類 → 第 4 段卡方 → 第 5 段 F/T 檢定。
4Console 最後會印出兩張表：chi_table 與 num_table，這就是報告要的結果。

💻 程式碼在做什麼

# 讀檔（注意分隔符是「分號」不是逗號！）
bank <- read.csv("MKT_data/bank.csv", sep = ";")

# 移除 6 個欄位
drop_cols <- c("job","contact","pdays","poutcome","month","day")
bank2 <- bank[, setdiff(names(bank), drop_cols)]

# 類別型：卡方檢定（p < 0.05 → 與 y 顯著相關）
chisq.test(table(bank2$marital, bank2$y))

# 數值型：先 F 檢定，再 T 檢定
ft <- var.test(bank2$age ~ bank2$y)                      # 步驟1：變異數是否相等
tt <- t.test(bank2$age ~ bank2$y, var.equal = ft$p.value >= 0.05)  # 步驟2：平均數是否相等

🔍 怎麼看結果

欄位意義判斷標準
chi_table$p.value卡方檢定的 p 值p < 0.05 → 該類別特徵與 y 顯著相關 → 適合區隔
num_table$F.p.value變異數是否相等的 p 值p ≥ 0.05 → 變異數相等（Used var.equal = TRUE）
num_table$t.p.value平均數是否相等的 p 值p < 0.05 → 兩組平均顯著不同 → 適合區隔
報告要寫什麼 ① 列出「卡方 p<0.05」與「t 檢定 p<0.05」的特徵清單 → 這些就是適合區隔的特徵。
② 管理意涵：針對顯著特徵刻畫目標客群輪廓（例：哪種婚姻狀態、教育程度、平均餘額較高的人更願意參加），把行銷資源優先投入這群人。

題目二關聯規則 — 中位數離散化（bank）

📄 作業原文（English Original）

Based on bank dataset, remove the following columns: job, contact, pdays, poutcome, month, and day. For the column "age", discretize the age into three levels (young <= 35, adult 35~55, old > 55). For the remaining numeric features, using "median" to cut the attributes into two levels: low and high, and treat "y" as the RHS. (a) Identify the significant rules with respect to the RHS ("y-yes" or "y-no"). (b) Count the frequency for each feature shown in the LHS and prioritize the features with respect to the RHS ("y-yes" or "y-no"). (c) Specify managerial insights for the results.

📋 題目說明

同樣用 bank 資料集、同樣移除那 6 個欄位，然後：

  • age（年齡）離散化為三級：young ≤ 35adult 35~55old > 55
  • 其餘數值特徵：用中位數（median）切成兩級 lowhigh
  • 把「y」當作規則右側（RHS）

任務：(a) 找出對應 y-yes / y-no 的顯著規則 → (b) 統計各特徵出現在 LHS 的頻率並排出優先順序 → (c) 提出管理意涵。

🖱️ 操作步驟

1開啟 R/hw2_q2.R。
2先單獨執行 library(arules) 那一行，確認沒有紅字錯誤。
3依序執行第 1 段（讀取清理）→ 第 2 段（離散化）→ 第 3 段（轉 transactions）。
4執行「(a) 顯著規則」段，Console 會印出 rules_yes / rules_no 各自前 10 名規則。
5執行頻率統計段，得到 freq_yes / freq_no（特徵優先順序）。

💻 程式碼在做什麼

# age 切三級
bank$age <- cut(bank$age, breaks = c(-Inf, 35, 55, Inf),
                labels = c("young", "adult", "old"))

# 其餘數值 → 中位數切 low/high
med <- median(bank$balance)
bank$balance <- ifelse(bank$balance <= med, "low", "high")

# 轉成關聯規則用的 transactions
bank[] <- lapply(bank, factor)     # 全部轉 factor
trans <- as(bank, "transactions")  # item 會自動命名成「欄位=水準」，如 y=yes

# 限定 RHS = y=yes 來找規則
rules_yes <- apriori(trans, parameter = list(supp = 0.02, conf = 0.35),
                     appearance = list(rhs = "y=yes", default = "lhs"))
門檻值（supp / conf）為什麼怪怪的？ 因為「會參加促銷」的樣本只占約 11%，門檻設太高會一條規則都找不到。 腳本裡 y=yes 用 supp=0.02, conf=0.35、y=no 用 supp=0.03, conf=0.6，是實測後能跑出規則的值。 若你跑出來是「0 條規則」，就把 supp 再調低（例如 0.01）。

🔍 怎麼看結果

  • inspect(...) 印出的表：support（出現比例）、confidence（可信度）、lift（提升度，>1 才有意義）。
  • freq_yes 由高到低就是「會參加的客群，關鍵特徵的優先順序」。
報告要寫什麼 (a) 摘錄 2~3 條最強規則；(b) 給出 y=yes / y=no 各自的特徵優先順序表； (c) 管理意涵：freq_yes 高的特徵＝會參加的客群，資源優先投入；freq_no 高＝不參加的輪廓，可用來排除或改溝通策略。

題目三關聯規則 — 醫療洞察（pima）

📄 作業原文（English Original）

Based on pima dataset, remove samples with zeros in the following columns: Glucose, BloodPressure, SkinThickness, Insulin, and BMI. Then, use Q1 and Q3 to cut the attributes into three levels: low, medium, or high. Apply association rule mining to gain medical insights by observing the LHS coupled with the specific "RHS=Yes" or "RHS=No". Use frequency count to indicate the top key indicators with the specific setting, "RHS=Yes" or "RHS=No", respectively (i.e. what features and corresponding levels are most commonly shown in the LHS for conditions, such as "RHS=Yes" or "RHS=No").

📋 題目說明

以 pima（糖尿病）資料集為基礎，先移除以下欄位中數值為 0 的樣本（視為缺失值）： GlucoseBloodPressureSkinThicknessInsulinBMI。

接著用 Q1 與 Q3（第一、第三四分位數）把各屬性切成三級：lowmediumhigh。

套用關聯規則探勘，分別在 RHS=Yes 與 RHS=No 兩種設定下，用頻率統計找出最關鍵的指標 （哪些特徵＋等級最常出現在 LHS）。

🖱️ 操作步驟

1開啟 R/hw2_q3.R。
2執行 library(arules)，再執行第 1 段讀取 data/Pima.csv。
3依序跑：第 2 段（移除 0 值樣本）→ 第 3 段（Q1/Q3 切三級）→ 第 4 段（轉 transactions + 產規則）。
4最後跑頻率統計段，會得到 freq_yes / freq_no，以及「特徵+等級」的組合頻率 item_freq_yes / item_freq_no。

💻 程式碼在做什麼

# 移除指定欄位中有 0 的樣本
zero_cols <- c("Glucose","BloodPressure","SkinThickness","Insulin","BMI")
keep    <- apply(pima[, zero_cols], 1, function(r) all(r != 0))
pima2   <- pima[keep, ]

# Q1 / Q3 切三級
q <- quantile(pima2$Glucose, c(0.25, 0.75))
pima2$Glucose <- cut(pima2$Glucose, breaks = c(-Inf, q[1], q[2], Inf),
                     labels = c("low","medium","high"))

# Outcome 轉成 Yes / No 當 RHS
pima2$Outcome <- factor(ifelse(pima2$Outcome == 1, "Yes", "No"))

🔍 怎麼看結果

  • inspect(head(sort(rules_yes, by="lift"), 10))：RHS=Yes 最強的 10 條規則（lift 越高越強）。
  • freq_yes：只看「特徵名」的出現次數排序。
  • item_freq_yes：看「特徵＋等級」的組合，例如 Glucose=high 出現幾次 —— 這是題目要的「關鍵指標」。
報告要寫什麼 分別針對 RHS=Yes（罹病）與 RHS=No（未罹病），列出最常出現的特徵與等級， 並以醫療角度解讀（例：血糖 high、BMI high 最常伴隨罹病 → 篩檢與衛教重點）。

8. 報告架構範例

四題合起來可以寫成一份短報告，建議結構：

寫報告的偷吃步 R 的輸出（chi_table、num_table、inspect(...)）可以整段複製貼上報告， 不用自己重新打字，也避免抄錯數字。

9. 常見錯誤排除

cannot open file 'MKT_data/bank.csv'

工作目錄不對。確認你有跑每個檔最前面的環境設定那段（會自動切換工作目錄）。 可在 Console 打 getwd() 檢查目前位置，應該顯示到 ...H2/作業。 若顯示到 ...H2（少了「作業」），就是那段還沒跑到。

there is no package called 'arules'

在 Console 執行：install.packages("arules", method = "wininet")，裝好後再 library(arules)。

object 'bank' not found

你跳段執行了。請從第 1 段重新依序跑到出錯的那段為止（資料要先讀進來，後面的段落才能用）。

題目二規則跑出 0 條

門檻太嚴。把 supp 調低（例如 y=yes 從 0.02 → 0.01）、或 conf 調低（0.35 → 0.3），再重跑 apriori。

cannot open file 'phone_scores.csv'

題目四的評分檔還沒建立。請照「題目四 → 前置作業」建立 CSV，並確認檔案放在「作業」資料夾、檔名與大小寫完全一致。

bank.csv 讀進來只有 1 欄 / 欄位黏在一起

bank.csv 的分隔符是分號 ; 不是逗號。讀檔一定要加 sep = ";"，腳本裡已經加好了。
