Common Methods of Estimation
Holdout
– Reserve 2/3 for training and 1/3 for testing 
Cross validation ( 交叉驗證)
– Partition data into k disjoint subsets
– k-fold: train on k-1 partitions, test on the remaining one
– 若有1000 筆資料(k=10 等分) ，選擇900 筆建模，100 筆
驗證；因100 筆可以輪替10 回，最後將10 次績效取平均
當作最終結果
Stratified sampling ( 分層抽樣)
– oversampling vs. undersampling
Bootstrap ( 抽出又放回抽樣)
– Sampling with replacement

Nearest-Neighbor Classifiers

Requires three things
– The set of stored records
– Distance Metric to compute 
distance between records
– The value of k, the number of 
nearest neighbors to retrieve

To classify an unknown record:
– Compute distance to other 
training records
– Identify k nearest neighbors 
– Use class labels of nearest 
neighbors to determine the 
class label of unknown record 
(e.g., by taking majority vote)

最近鄰居法總結 
KNN classifiers are called lazy learners ( 懶惰學習
器)
– It does NOT build models explicitly
– 原理簡單，但效果不差
– KNN 需計算歐式距離，所以X 變數需為數值型
– 不同單位的X 變數，先進行正規化( (X-Xmin)/ 
(Xmax-Xmin) ) ，避免單位對分類造成困擾
– KNN 無法指出哪個X 變數對分類較重要
– KNN 不是只有分類，還能進行迴歸，原理是取
最近K 個鄰居的Y 值平均後當作預測值

Naïve Bayes 假設所有的屬性彼此獨立
Assume independence among attributes Ai when class is given:  
  
– P(A1, A2, …, An |C) = P(A1| Cj) P(A2| Cj)… P(An| Cj)
 
– Can estimate P(Ai| Cj) for all Ai and Cj.
– New point is classified to Cj if  P(Cj)  P(Ai| Cj)  is 
maximal ( P(Ai| Cj) =P(A1| Cj) P(A2| Cj)… P(An| Cj)).

羅吉斯迴歸 (Logistic Regression)
Logistic 迴歸是以迴歸模式來建立一個依變數Y 與
一個或多個預測變數X 之間的分類關係，Logistic
迴歸所探討結果的依變數是離散型，特別是其分類
只有二元 ( 如“正常與異常”、“良性與惡性”、
“存活與死亡” ) 或少數幾類時( 多元羅吉斯) 。 
Logistic 迴歸的目的是在於建立一個最精簡和最能配
適(fit) 的分析結果，Logistic 迴歸不需要假設分配
類型，在Logistic 分配中，自變數(X) 對於依變數
(Y) 之影響方式是以指數的方式來變動，即y=ef(x)。

Logistic Regression ( 總結)
對雜訊與不相干的屬性較敏感而易受干擾
能夠同時接受數值型或間斷型的X 變數
只能進行分類(Y 類別) ，無法進行迴歸(Y 數值)
可以告訴使用者哪個X 變數重要( 迴歸係數顯著)
最大的優點是呈現不同預測類別的相對機率 ( 如
計算healthy, risky, sick 三類的相對機率)

ROC (Receiver Operating Characteristic)
Developed in signal detection theory to analyze noisy 
signals and characterize the trade-off between positive 
hits ( 精準度) and false alarms ( 靈敏度)
如何評估分類器績效: ROC curve plots TP (on the y-
axis) against FP (on the x-axis)
統計學上的型一錯誤(false alarm- 沒病誤判成有
病) 與型二錯誤(miss alarm- 有病誤判成沒病), 哪
種情況嚴重?
