# 國際行銷 — 文件索引（doc）

> 本資料夾把「投影片教材 / 檔案資料 / 作業 / R 環境」整理成 Markdown，方便隨時查找與向 agent 提問。
> 每個 md 都標明**原始檔案路徑**，可精準對照。

## 這個工作區有什麼

| 資料夾 | 內容 |
|--------|------|
| `投影片教材/` | 王志軒老師 9 份授課 PDF（行銷理論 + 統計/資料探勘方法） |
| `檔案資料/` | 教學用資料集 `data/`（86 檔）、`MKT_data/`（100 檔）＋ Excel 案例＋ R 環境測試 |
| `H1/作業/` | 作業一（Excel 實作） |
| `H2/作業/` | 作業二（R：統計檢定 / 關聯規則 / MDS） |
| `H3/作業/` | 作業三（R：AHP / TOPSIS / Kano / BIP，含 3 個資料 CSV，已驗證可重跑） |

## 快速用法（問 agent 時）

- 「投影片 `基礎分類` 第 12 頁在講什麼？」→ 查 `slides/基礎分類.md`
- 「`bank.csv` 有哪些欄位、用在哪一題？」→ 查 `資料檔清單.md`
- 「HW2 題目二要用哪支腳本、什麼套件？」→ 查 `作業整理.md`
- 需要投影片**全文原文**（非整理）→ 查 `_raw/slides/*.txt`

## 重新產生（若投影片/資料更新）

```powershell
# 投影片 PDF → txt
$py = 'D:\Programs\Python\Python312\python.exe'
& $py 'doc\_tools\extract_pdf_text.py' '投影片教材' 'doc\_raw\slides'
```

> 備註：投影片 PDF 為**文字式**（非掃描）抽查；`投影片教材.md` 的頁碼對照即來自抽取文字。
> 若某份未來變成掃描檔，抽取字元數會偏低，需改以檔名/目錄判讀。
