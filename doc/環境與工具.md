## R 環境測試

`檔案資料/R環境測試.R` — 用來確認 R + 繪圖是否正常：
```r
x <- rnorm(200, mean = 170, sd = 8)
summary(x)
hist(x, col = "steelblue", main = "R 環境測試")
```
游標放在任一行按 `Ctrl+Enter` 逐行送入 R 終端機；`summary(x)` 應在 Console 出現，直方圖應在繪圖視窗出現。

## 資料讀取注意事項

| 檔案類型 | 讀法 |
|----------|------|
| `bank.csv` | `read.csv(..., sep = ";")`（分號分隔） |
| `churn.txt`, `TelRepair.txt`, `glass.txt`, `imports-car.txt` | `read.table(..., header = FALSE)`（**無標題列**） |
| `iris.csv` | 欄名為 `Saving, Inflation, Income, Consumption, Species`（非標準 iris） |
| 中文欄名（`3year_stock.csv` 等） | 以 UTF-8 讀取；Windows 下留意編碼 |
| `Wifi_data.csv`（19937×523）、`creditcard.csv`（284807×31） | 資料量大，讀取較慢 |
