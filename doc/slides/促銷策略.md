## 重點概念

- **購買決策模式**：need recognition → 資訊搜尋 → 評估 → 購買 → 購後行為。
- **衝動性 vs 強迫性購買**：前者臨時觸發；後者為強迫症行為。
- **TAM**：知覺有用性 + 知覺易用性 → 使用態度 → 使用意圖。
- **推薦模式**：① 內容導向（item 相似）② 協同過濾（user 相似）③ 混合。
- **通膨三種利率**：
  - **實質利率** $i$（real）：$i=\dfrac{i'-f}{1+f}$
  - **市場（名目）利率** $i'$（market）
  - **通膨率** $f$
  - 現值計算：$PW=\text{(名目現金流)} \times\dfrac{1}{(1+i)^n}$（以實質利率折現）
  - 實務規則：**以市場利率折現名目現金流**，或**以實質利率折現實質現金流**，兩者一致。
