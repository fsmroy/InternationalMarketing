## 重點概念

- **品質成本四類**：預防（Prevention）、鑑定（Appraisal）、內部失敗（Internal failure）、外部失敗（External failure）。
- **TQM 三支柱**：顧客滿意、員工參與、持續改善。
- **持續改善**：Kaizen + PDCA（Plan-Do-Check-Act = Deming Wheel）。
- **六標準差**：**降低離散度（spread）**＋**對準目標（center）**；衡量能力以不良率（DPPM/十億分之比）表示。
- **品質哲學**：顧客滿意的多面向 = 符合規格、價值、適用性、支援、心理印象。
- **Kano 五（六）類品質**（以「有 vs 沒有」交叉判定）：
  - **A 魅力（Attractive）**：有→喜愛、無→沒感覺
  - **M 必需（Must-be）**：無→厭惡（基本門檻）
  - **O 一元（One-dimensional）**：有→喜愛、無→厭惡（線性）
  - **I 無差異（Indifferent）**：有無都無感
  - **R 反轉（Reverse）**：有反而更差
  - **Q 問題（Questionable）**：答題矛盾的無效回答
- **Kano 滿意度公式**：
  - $d_i^+=\dfrac{A_i+O_i}{A_i+O_i+M_i+I_i+R_i}$（有屬性時的「愉悅」係數）
  - $d_i^-=-\dfrac{M_i+O_i}{A_i+O_i+M_i+I_i+R_i}$（無屬性時的「厭惡」係數）
  - $S_j=p_j\cdot d_j^+ +(1-p_j)\cdot d_j^-$，其中 $p_j$ 為屬性 j 的績效（如分數 4/5 = 0.8）
- **問卷五級反應**：我喜愛 / 我期待 / 我沒感覺 / 我勉強 / 我厭惡。
