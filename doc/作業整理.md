## HW2 — R：市場區隔 / 關聯規則 / MDS

> 題目原文與中文翻譯：`H2/作業/2026-MKT-HW2.md`
> 執行環境：RStudio 逐段 `Ctrl+Enter`；腳本內已 `setwd` 到 `H2/作業`

### 題一 — 市場區隔統計檢定（`bank.csv`）
- 移除欄位 `job, contact, pdays, poutcome, month, day`
- 類別特徵 → **卡方獨立性檢定**；數值特徵 → **F 檢定（變異數）→ T 檢定（平均數）**
- 腳本：`R/hw2_q1.R`｜套件：**無（base stats）**
- 讀取注意：`read.csv(..., sep=";")`（分號分隔）
- 判定：`p<0.05` 的特徵即適合作市場區隔 → 寫管理意涵

### 題二 — 關聯規則（`bank.csv`，`y` 為 RHS）
- `age` 切三級（≤35 / 35–55 / >55）；其餘數值以 **中位數** 切 low/high
- (a) 找顯著規則 (b) 統計 LHS 各特徵頻率並排序 (c) 管理意涵
- 腳本：`R/hw2_q2.R`｜套件：**arules**

### 題三 — 關聯規則醫療洞察（`Pima.csv`）
- 移除 Glucose/BloodPressure/SkinThickness/Insulin/BMI **為 0** 的樣本
- 以 **Q1 / Q3** 切 low/medium/high
- 分別在 `RHS=Yes` / `RHS=No` 下用頻率找關鍵指標
- 腳本：`R/hw2_q3.R`｜套件：**arules**

### 題四 — MDS 手機產品定位
- 8 個產品系列 × 10 屬性（A1 品牌知名度 … A10 錄影），**5 點李克特**評分 → 平均 → MDS → 2D 圖
- 腳本：`R/hw2_q4.R`｜套件：**無（`cmdscale`）**，需先備妥 `phone_scores.csv`
- 譯註：原文寫「seven product series」但列 8 個，建議與老師確認
- 對照投影片：`品牌定位.md`

> **待補資料**：`bank`（在 `MKT_data/` 已有）、`pima`（`檔案資料/` 有）、組員手機評分 CSV。

## HW3 — R：AHP / TOPSIS / Kano / BIP

> 題目原文與中文翻譯：`H3/作業/2026-MKT-HW3.md`
> 腳本說明：`H3/作業/R-code/README.md`
> 執行：於 `R-code` 資料夾 `Rscript run_all.R`（或 RStudio Source）

| 腳本 | 題目 | 內容 | 套件 |
|------|------|------|------|
| `P1_AHP.R` | Problem 1 | 二階層 AHP：六準則權重、一致性 CR、三城市加權總分、階層圖 | 純 base R |
| `P2_TOPSIS.R` | Problem 2 | 以 TOPSIS 取代第二階層，PIS=5/NIS=1、沿用 P1 權重、CC 貼近度與排名 | 純 base R |
| `P3_Kano.R` | Problem 3 | Kano：`delight=(A+O−I)/N`、`disgust=−(M+O−R)/N`、熵權重、散布圖 | 純 base R |
| `P4_BIP.R` | Problem 4 | 二元整數規劃：窮舉 2⁴=16 組合、三段價格最佳配置、敏感度分析 | 純 base R |
| `run_all.R` | 全部 | 依序執行四題 | — |

**產出圖檔**：`P1_AHP_hierarchy.png`、`P2_TOPSIS_scores.png`、`P3_Kano_plot.png`、`P4_BIP_config.png`（中介檔 `P3_kano_result.rds`）

### 題目要點
- **P1**：三港口城市（高雄/釜山/東京）× 六準則（生活成本、自然環境、城市觀光、食物、交通、禮儀）→ 成對比較 → 平均權重 → 加權分數。
- **P2**：同一資料改用 TOPSIS，五點量表、PIS/NIS 固定 → 比較 AHP 與 TOPSIS 結果差異。
- **P3**：智慧手機四功能（防水、光學變焦、無線充電、摺疊螢幕）之 Kano 分類 → delight / disgust。
- **P4**：基礎成本 10,000、功能成本 2500/3500/1500/155000(疑筆誤)，目標最大化 delight 或最小化 disgust，價格分群 high 30000 / medium 22000 / low 15000。

### 原文疑義（程式中已處理）
| 位置 | 疑義 |
|------|------|
| P1 | 寫「four criteria」但列六項準則 → 程式一律用六項 |
| P4 | foldable 成本 155000 遠大於其他且超過所有預算 → 附敏感度分析（5000/15000） |
| Kano 公式 | 採 `多準則決策.xlsx` 版本，與講義可能略異 |

> **對照投影片**：`通路管理.md`（AHP/TOPSIS）、`服務品質與問卷設計.md` + `產品策略.md`（Kano）、`促銷策略.md`（NPV/現金流）。
