1. 作業內容說明與解釋

本作業分為四個連貫的題目，主軸是「多準則決策（MCDM）」與「顧客需求分析」，最後用數學規劃做產品分群。以下逐題說明「要做什麼、用到什麼方法、對應公式」。

Problem 1 — 以 AHP 對三個港口做二階層評估

任務：對三個港口城市 Kaohsiung 高雄 Busan 釜山 Tokyo 東京 做 two-level（二階層）AHP 評估。準則為：living cost、natural environment、city tourism、food、transportation、courtesy（共六項）。

要產出：

  1. 畫出評估流程的階層圖（Goal → Criteria → 二階 Alternatives）。
  2. 依團隊成員的成對比較，計算各準則的權重（取平均）。
  3. 對所有準則分別評估三個城市（第二階層的成對比較）。
  4. 計算三個城市的加權總分並排名。
AHP 權重公式（平均法 / 課程 Excel 採用的做法）： 對成對比較矩陣 $A=[a_{ij}]$（$a_{ij}=1/a_{ji}$，對角為 1）先逐欄正規化： $$\tilde a_{ij}=\frac{a_{ij}}{\sum_{k=1}^{n}a_{kj}}$$ 再對每一列取平均，得到權重： $$w_i=\frac{1}{n}\sum_{j=1}^{n}\tilde a_{ij}$$ 權重總和 $\sum_i w_i = 1$。

一致性檢定（Consistency）：AHP 需檢查判斷矩陣是否一致。

$$\lambda_{max}\text{（最大特徵值）},\quad CI=\frac{\lambda_{max}-n}{n-1},\quad CR=\frac{CI}{RI}$$

$CR<0.1$ 視為可接受。RI 查表：

R.I.0.580.901.121.241.321.411.451.49

Problem 2 — 用 TOPSIS 取代第二階層的 AHP

任務：沿用 Problem 1 求得的準則權重，但把第二階層改用 TOPSIS 評估三城市。以五點李克特量表計分，PIS = (5,5,5,5,5,5)、NIS = (1,1,1,1,1,1)。最後討論 AHP 與 TOPSIS 結果差異。

TOPSIS 五步（課程講義 通路管理 p.55–65 的標準流程）：
  1. Step 1 建立決策矩陣 $x_{kj}$（方案 × 準則）與權重 $w_j$。
  2. Step 2 正規化：$r_{kj}=\dfrac{x_{kj}}{\sqrt{\sum_k x_{kj}^2}}$，加權 $v_{kj}=w_j\,r_{kj}$。
  3. Step 3 決定正理想解 $A^*$（benefit 取 max、cost 取 min）與負理想解 $A^-$（反之）。
  4. Step 4 計算各方案與理想解距離 $$D_k^+=\sqrt{\sum_j (v_{kj}-v_j^*)^2},\qquad D_k^-=\sqrt{\sum_j (v_{kj}-v_j^-)^2}$$
  5. Step 5 計算貼近度並排名 $$C_k=\frac{D_k^-}{D_k^+ + D_k^-}\in[0,1]$$

本題簡化為「以加權距離直接比較」——範本 Excel 用的是加權歐氏距離版本（見第 2 節說明）。

Problem 3 — Kano 模型評估智慧型手機功能

任務：對四項功能 water proof optical zoom wireless charging foldable screen 做 Kano 評估，依團隊成員的 Kano 分類百分比，推導 delight（滿意度） 與 disgust（不滿意度）。

Kano 分類：A（Attractive 魅力）、M（Must-be 必備）、O（One-dimensional 一維）、R（Reverse 反向）、I（Indifferent 無差異）、Q（Questionable 可疑）。

對應公式（課程講義 服務品質與問卷設計 p.16–17）： $$\text{Delight}_i=\frac{A_i+O_i}{A_i+M_i+O_i+I_i}\qquad(\text{正值}\ 0\sim1)$$ $$\text{Disgust}_i=-\,\frac{O_i+M_i}{A_i+M_i+O_i+I_i}\qquad(\text{負值}\ -1\sim0)$$
重要：拆解出的課程範本 Excel（多準則決策.xlsx 之 Kano 工作表）實際公式為： Delight=(A+O−I)/N、Disgust=−(M+O−R)/N（分母 N 不含 Q）。 這與講義 p.16 的標準式不同（講義版分母僅 A+M+O+I，且無 −I/−R 項）。 交作業前務必釐清要用哪一版（本作業的 R 程式採範本 Excel 版）。

Problem 4 — 二元整數規劃做價格基礎分群

任務：承接 Problem 3，用 BIP（Binary Integer Programming）做價格基礎顧客分群，目標為「最大化 delight」或「最小化 disgust」，對 high / medium / low 三個價格分群找出最佳產品配置。

參數：基礎成本 10,000；功能成本 water proof = 2,500、optical zoom = 3,500、wireless charging = 1,500、foldable screen = 155,000。

模型（決策變數 $y_f\in\{0,1\}$ 表是否搭載功能 $f$）： $$\max\ \sum_f w_f\,d_f\,y_f \quad(\text{或}\ \min\ \sum_f w_f\,e_f\,(1-y_f))$$ 限制式為成本上限（依分群價格）： $$10000+\sum_f c_f\,y_f \le P_{\text{segment}},\qquad y_f\in\{0,1\}$$ 其中 $d_f$ = delight、$e_f$ = disgust（Problem 3 求得）、$w_f$ = 功能權重。
原文疑義：foldable screen 成本寫 155000，遠高於其他功能，極可能為 5000 或 15000 之筆誤，請向老師確認。

4.1 Problem 1 步驟（AHP）

畫階層圖：最上層 Goal（選最佳港口）、中層 Criteria（六準則）、下層 Alternatives（高雄/釜山/東京）。可用 PowerPoint、draw.io 或 R（DiagrammeR）。
建立準則成對比較矩陣：對每一對準則比較重要性（1–9 與倒數），每位成員各一份。
正規化求權重：逐欄除以欄和，再對每列平均（見 §1 公式）。多成員則對各成員權重取平均。
一致性檢定：以 eigen() 求 $\lambda_{max}$，算 $CI$、$CR$，確認 $CR<0.1$。
對每個準則，建三個城市的成對比較矩陣並求局部分數（第二階層）。
加權彙總：$\text{Score}_k=\sum_j w_j \cdot s_{kj}$，得出三城市排名。
# AHP 核心（節錄；完整可執行版見 作業\R-code\P1_AHP.R）
A <- matrix(c(1,1/2,2,1,  2,1,3,2,  1/2,1/3,1,1,  1,1/2,1,1), nrow=4, byrow=TRUE)
col_sum <- colSums(A)
norm <- sweep(A, 2, col_sum, "/")     # 逐欄正規化
w <- rowMeans(norm)                   # 準則權重
lambda_max <- Re(eigen(A)$values[1])  # 最大特徵值
n <- nrow(A); CI <- (lambda_max-n)/(n-1); RI <- 0.90; CR <- CI/RI
print(round(w,4)); print(round(CR,4)) # CR 需 < 0.1

4.2 Problem 2 步驟（TOPSIS）

整理評分矩陣：三城市 × 六準則（五點量表；此為 local score，可用團隊評分平均）。
帶入 PIS=(5,5,5,5,5,5)、NIS=(1,1,1,1,1,1)。
以 Problem 1 的權重 $w_j$ 計算加權距離： D+ = sqrt(sum(w_j*(x-PIS)^2))、D- = sqrt(sum(w_j*(x-NIS)^2))。
算貼近度 Ratio = D-/(D++D-) 並排名。
討論差異：AHP 為相對比較、逐準則兩兩比較；TOPSIS 為與理想解距離之妥協解。比較排名是否一致，並說明原因（權重保留、評分基礎不同）。
# TOPSIS 核心（節錄；完整可執行版見 作業\R-code\P2_TOPSIS.R）
X   <- rbind(Kaohsiung=c(5,4,3,4,4,4),
             Busan    =c(4,4,4,4,4,4),
             Tokyo    =c(3,4,5,3,4,3))
PIS <- rep(5, ncol(X)); NIS <- rep(1, ncol(X))
Dp  <- sqrt(rowSums(sweep((X-PIS)^2, 2, w, "*")))
Dn  <- sqrt(rowSums(sweep((X-NIS)^2, 2, w, "*")))
ratio <- Dn/(Dp+Dn)
print(round(sort(ratio, decreasing=TRUE),4))   # 貼近度越高越佳

4.3 Problem 3 步驟（Kano）

發放 Kano 問卷（每功能一組正向/反向題），統計每位／全體的 A、M、O、R、I、Q 比例。
計算每個功能的 Delight = (A+O−I)/N、Disgust = −(M+O−R)/N，$N=A+M+O+R+I$（不含 Q）。 本作業 R 程式採範本 Excel 版；講義 p.16 版為 (A+O)/N、−(O+M)/N（$N=A+M+O+I$，不計 R）， 交作業前務必確認用哪一版。
（可選）以熵權重求各功能權重，供 Problem 4 使用——範本用 K = -Σ p·ln p / ln 5、Weight = (1-K)/Σ(1-K)。
判讀各功能屬性：A 為魅力、M 為必備、O 為一維。

4.4 Problem 4 步驟（BIP）

以 Problem 3 的 delight / disgust 與功能權重建立目標函數。
設定決策變數 $y_f\in\{0,1\}$（四功能）。
建立成本限制式：$10000+\sum c_f y_f \le P$，$P\in\{15000,22000,30000\}$。
分別對 high / medium / low 求解最大 delight（或最小 disgust）的最佳產品組合。
可用 Excel 規劃求解，或用 R lpSolve：
# BIP（節錄；完整可執行版見 作業\R-code\P4_BIP.R，內含 base R 窮舉與 lpSolve 兩種寫法）
library(lpSolve)
c_f  <- c(2500, 3500, 1500, 5000)   # 功能成本（foldable 以確認後的數字為準）
val  <- c(0.45, 0.55, 0.60, 0.50)   # delight（或改用 -disgust）
for (P in c(15000, 22000, 30000)) {
  res <- lp("max", val, matrix(c_f, nrow=1), "<=", P-10000, all.bin=TRUE)
  cat(sprintf("P=%d  選用功能=%s  delight=%.3f\n",
              P, paste(which(res$solution==1), collapse=","), res$objval))
}
